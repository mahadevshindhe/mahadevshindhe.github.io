AI Learning Plan – Week 2 (Solution Architect Track)

Theme: Machine Learning Foundations for Architects

This week builds architectural understanding of ML pipelines, model lifecycle, data flows, and deployment patterns.

Day 1 – Machine Learning Landscape

  • Types of ML: Supervised, Unsupervised, Reinforcement
  • How ML fits into enterprise architecture
  • Architectural patterns: Batch vs Real-time ML
  • Hands-on: Explore ML APIs (Azure ML / AWS Sagemaker / GCP Vertex)

Day 2 – ML Pipeline Architecture

  • Data ingestion → Feature engineering → Training → Evaluation → Deployment
  • ETL/ELT with ML: key considerations
  • Architectural design of feature stores
  • Hands-on: Build a dummy ML pipeline diagram

Day 3 – Model Training & Storage

  • Model training architectures (distributed, GPU, autoscaling)
  • Model registries (MLflow, Sagemaker Model Registry, Vertex)
  • Model versioning and lineage in enterprise systems
  • Hands-on: Register a model in MLflow locally

Day 4 – Model Deployment Patterns

  • Deployment patterns: Batch scoring, Online inference, A/B testing
  • Edge vs Cloud deployment considerations
  • Scaling inference endpoints
  • Hands-on: Deploy a mock REST ML inference endpoint

Day 5 – MLOps Foundations

  • MLOps vs DevOps: architectural differences
  • Continuous Training (CT), Continuous Deployment (CD)
  • Monitoring drift, bias, model performance
  • Hands-on: Create a simple MLOps architecture diagram

Deliverables for Week 2

  • Architectural diagram of a complete ML pipeline
  • Model lifecycle (versioning + deployment) blueprint
  • Comparison sheet: Batch vs Real-time ML inference
  • Mini MLOps architecture + tool selection
